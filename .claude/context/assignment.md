Тестовое задание: Веб-приложение для отображения и фильтрации фильмов (Angular)

Цель:
Создать веб-приложение на последней стабильной версии Angular для отображения и поиска фильмов с использованием API The Movie Database (TMDb).


Общие требования:
Использовать официальный API TMDb для получения данных о фильмах:
Документация TMDb API
Приложение должно включать минимум три основных элемента (наименования условные — структура и нейминг остаются на усмотрение кандидата):
Компонент для списка фильмов (например, MovieListComponent)
Компонент для отображения карточки фильма (например, MovieCardComponent)
Компонент для детальной информации о фильме (например, MovieDetailComponent)
Обязательно использовать:
Angular Signals для управления состоянием и реактивными данными
Tailwind CSS для стилизации
Standalone Components
Новые возможности шаблонов Angular (@if, @for, @switch и т.п.)
Функциональные требования:
1. Работа с API
Создать сервис (например, MovieService) для взаимодействия с TMDb API.
Он должен реализовывать минимум следующие методы:
getPopularMovies() — получение списка популярных фильмов
searchMovies(keyword: string) — поиск фильмов по ключевому слову
getMovieDetails(id: number) — получение подробной информации по идентификатору фильма
Сервис должен:
использовать Angular signals для хранения и реактивного обновления данных;
предусматривать ошибки, загрузку (например, loadingSignal, errorSignal, moviesSignal).
2. Список фильмов
Создать компонент для отображения списка фильмов:
Должен получать данные через сервис;
Поддерживать состояние загрузки и отображение ошибок;
Каждый фильм должен быть отдельным компонентом карточки, содержащим:
постер
название
краткое описание (overview)
При клике на карточку открывается страница с детальной информацией (роутинг).
3. Поиск фильмов
Добавить компонент поиска:
Поле ввода + кнопка “Поиск”;
При вводе ключевого слова должны динамически фильтроваться результаты;
Если поле очищено — возвращается список популярных фильмов.
4. Детальная страница фильма
Создать компонент для детального просмотра:
Отображает: название, постер, описание, жанры, рейтинг, дату выхода;
Реализовать переход с помощью Angular Router;
Желательно предусмотреть кнопку “Назад”.
5. UI и стилизация
Использовать Tailwind CSS для оформления;
Приложение должно быть адаптивным и аккуратным визуально;
