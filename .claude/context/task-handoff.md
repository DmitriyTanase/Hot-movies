## Architecture Constraints (approved)

- Use the pinned CLI only: `npx @angular/cli@22.2.2 …`. **Never** use the global `ng` (13.3.8). After install, use the project-local CLI (`npx ng …` or npm scripts).
- Keep the scaffold defaults: zoneless (no `zone.js`), OnPush default (no explicit `changeDetection` metadata), standalone components, strict TypeScript and templates, 2025 file naming.
- Use Tailwind v4 CSS-first. **No** `tailwind.config.js`. No component or UI library.
- **No** SSR, NgRx/SignalStore, extra runtime dependencies, interceptors, generators or lifecycle hooks.
- Dev-only additions allowed in this task: `angular-eslint` (and the ESLint packages it installs), `prettier`, `eslint-config-prettier`. Nothing else without approval.
- Do not add `provideHttpClient()`, MovieService, components, feature routes or any TMDb call.
- Git is human-controlled.
  - The safety hook (`.claude/hooks/safety.sh`) blocks `git commit`, `git push`, `git reset --hard`, `git clean`, `git rebase`, and discarding checkout/restore operations. Do not attempt to bypass it.
  - Read-only Git commands (`status`, `diff`, `check-ignore`, `ls-files`) are fine.

## Technical Notes

### 1. Pre-flight (read-only; report the outputs verbatim)

```
node -v
npm -v
where npm        (Git Bash: `where npm` or `which -a npm`)
npm config get prefix
```

- **Pass:**
  - `node -v` satisfies `^22.22.3 || ^24.15.0` (expected v24.21.0);
  - `npm -v` reports a modern npm, **≥ 10** (the bundled npm is 11.19.0).
- **Fail:** `npm -v` reports **8.11.0**. This is the global npm in `%APPDATA%\npm` shadowing the bundled one. **STOP and report.** The toolchain fix is a human action.
  - **Do not** install, upgrade or uninstall any global package.

- **Shell:** PowerShell blocks `npm.ps1` / `ng.ps1` (execution policy). Use the Bash tool (Git Bash), or `npm.cmd` / `npx.cmd` in PowerShell.

- `eslint.config.js` is not covered. Report this; do not edit `.gitattributes` (Open Question 3).
